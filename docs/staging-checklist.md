# Чек-лист после выкатки на стенд (staging.talk.perveev.com)

Проходить после каждой выкатки, до команды «на прод». Стенд — условные данные, DaData и отчётность в песочнице,
распознавание PDF выключено. Отметка «✓» — проверено, «✗» — записать, что не так, и не выкатывать на прод.

## 1. Стенд жив (1 минута)

- [ ] https://staging.talk.perveev.com открывается, замок в адресной строке без предупреждений.
- [ ] Вход тестовой учёткой проходит; неверный пароль — понятная ошибка.
- [ ] Внизу меню — имя и роль той учётки, под которой вошли.

## 2. Сквозной путь сделки (3–5 минут)

- [ ] **Главная:** плитки с числами, канбан по стадиям, блок «Требуют внимания» — клиенты по наименованию и ИНН, без кодов «КЛ-…».
- [ ] **Новая сделка:** создаётся по ИНН; дубль по тому же ИНН просит подтверждения.
- [ ] **Карточка сделки:** смена стадии, задача, файл — сохраняются и видны в ленте.
- [ ] **Канбан и список:** отбор и «Сбросить» работают, сделка находится поиском.
- [ ] **Клиенты:** карточка клиента открывается, правка сохраняется.

## 3. Мониторинг (3 минуты)

- [ ] Метка «Демонстрационные данные» и ключевая ставка ЦБ с датой видны в шапке.
- [ ] **Портфель и зоны:** плитки по зонам, график за 24 месяца, переходы, покрытие, таблица клиентов.
- [ ] В таблице и карточке — наименование и ИНН («ООО «Пример-…»», ИНН 000001…), кода «КЛ-…» на экране нет.
- [ ] Поиск по наименованию или ИНН находит клиента; щелчок по строке открывает карточку.
- [ ] **Карточка клиента:** балл, зона, «Почему такой балл», график балла и просрочки, договоры.
- [ ] **Как обучена модель:** 13 факторов, Gini с оговоркой об условных данных.
- [ ] **Загрузка выгрузки:** «Скачать шаблон» и «Скачать пример» скачивают xlsx; загрузка примера показывает все галочки,
      «Рассчитать портфель» пересчитывает, «Вернуться к демонстрационным данным» возвращает демо.
- [ ] Под ролью куратора загрузки нет (вместо неё — пояснение).

## 4. Остальные страницы (2 минуты)

- [ ] **Расчёт класса:** условный пакет считается, класс показан.
- [ ] **Проверка клиента:** по ИНН из списка демо — ответ (на стенде песочница).
- [ ] **Источники данных:** коннекторы со статусом, журнал запросов пополняется.
- [ ] **Задачи, О проекте, Схема процесса** открываются.

## 5. Телефон (2 минуты)

- [ ] С телефона по мобильному интернету: вход, главная, мониторинг — без горизонтальной прокрутки, меню открывается.

## 6. Тёмная тема (1 минута)

- [ ] При тёмной теме системы текст читается, графики и зоны различимы.

## 7. Сервер (выполняет Claude, вывод — в отчёте о выкатке)

- [ ] `docker ps`: стенд `healthy`, рабочий сайт и боты openclaw — в том же состоянии, что до выкатки.
- [ ] `docker stats`: стенд не выше 100 МБ, перезапусков нет (`RestartCount` = 0).
- [ ] `npm test` перед выкаткой — все тесты зелёные.
- [ ] Консоль браузера на проверенных страницах — без ошибок.

Если всё отмечено — команда «на прод»: `docker compose up -d --build --no-deps app`, затем пункты 1–3 на talk.perveev.com.
